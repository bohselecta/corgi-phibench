# Verification scope

Local acceptance platform: Linux x86_64; harness Python 3.12.14; sandbox Python
3.13.5; Node 24.19.0 used only to reconstruct the historical boundary checkpoint.
Public runtime is Python and distribution Bubblewrap/util-linux; no Node dependency.

The release tests run all six methods on bug-fix, feature and refactor tasks;
validate field/grammar bounds; attempt traversal, symlink, special-file,
read-only-write, host/secret/network/fork/thread/memory/output/scratch attacks;
check public regression handling, independent hidden judgment, unknown accounting,
manifest/receipt alteration, active writer exclusion and torn-tail recovery.
Fresh-context review additionally reproduced and drove repairs for frame-based
mutation-check spoofing, provider/run authorization mismatches, total HTTP
deadlines, price reconstruction, interrupted tool attempts and initialization
path conflicts. Regressions retain those counterexamples; unsupported syntax
fails the restricted argument-preservation proof.

`tests/acceptance.py` is a separately framed black-box process test: installed
interface semantics, all 18 matched combinations, independently recomputed
final artifact scores, offline report/export, repeatable replay, genuine SIGTERM
and SIGKILL model/tool recovery. This is automated verification; it is not a claim of human
acceptance or an independently authored scientific replication.

The offline observatory is inspected in Chromium at 1280×900 and 390×844.
Matrix rows/statuses, event scrubbing, select/previous/next/play controls,
keyboard focus, script-content escaping, empty receipts and reduced-motion
layout are checked. Context bytes and repository diffs come from saved events.
Screenshots show the null fixture with all 18 unsuccessful runs retained.

Clean packaging uses a fresh standalone clone and venv, installs a built wheel
with network disabled, runs the README's doctor/demo/verify path, then the
critical tests. There are no Python runtime dependencies to audit. Linux
runtime tools remain explicit external requirements. CI is configured for
Python 3.11/3.13 on Ubuntu; hosted CI is NOT RUN until publication.

Live provider/model experiments: NOT RUN. Package registry, GitHub Release,
release tag, paid deployment and website: NOT RUN / not authorized. ARM64,
macOS and Windows execution: NOT VERIFIED. Hash chains are not signatures.
The campaign evidence records exact revision, outcomes and candidate checksums.
